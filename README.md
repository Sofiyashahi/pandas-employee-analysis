# Employee Data Analysis with Pandas

Practice project exploring and cleaning an employee dataset using Python, Numpy and Pandas.

## Dataset
36 rows of employee data (department, city, salary, experience, performance score)
with intentional missing values and a duplicate row for cleaning practice.

## What I did
- Loaded and inspected data (`info`, `describe`)
- Handled missing values and removed duplicates
- Converted dates and engineered new features (`join_year`, `salary_per_year_exp`)
- Filtered, grouped and sorted data to answer questions such as average salary per department

## Tech
Python, Pandas, NumPy

## How to run
1. Clone this repo
2. `pip install pandas numpy`
3. Run the file
